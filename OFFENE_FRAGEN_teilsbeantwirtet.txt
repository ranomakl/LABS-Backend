1. Pumpe Longer WT600-2J
------------------------
[x] RS485-Adresse und Baudrate geändert?
    -> Werkseinstellung (Adresse 1, 1200 Baud, 8E1).
[x] Welcher Schlauch, wie viel mL pro Umdrehung?
    -> Standardmäßig Schlauch 3,2 x 6,4 mm (Innen- x Außendurchmesser).
    -> Faktor 0,8883 mL pro Umdrehung.
       Flussrate [mL/min] = Drehzahl [rpm] x 0,8883
    -> Bereich 60 bis 600 rpm, also 53,3 bis 533 mL/min.
[ ] Muss die Pumpe am Bedienfeld von lokal auf Fernsteuerung
    umgestellt werden?
    Grund: Die Pumpe hat auf über 480 Testframes kein Byte geantwortet.
    Wurde im Labor nicht gefragt. Selbst am Gerät prüfen.
[ ] Lesescan zur Bestätigung von Adresse und Baudrate steht aus.
[ ] Ack-Frame beim Schreiben ist geraten, die Blogquelle zeigt ihn nicht.

4. Inficon micro GC Fusion
--------------------------
[x] Eigenes Netz oder Institutsnetz?
    -> Muss über LAN angeschlossen werden (Direktverbindung, 10.10.0.1).
[x] Hinterlegte Methoden?
    -> Aktuelle Standardmethode: microGC_Standard_Method_calibrated_0726
    -> Etwa jedes halbe Jahr ändert sich nur die Endung "0726" auf den
       Monat und das Jahr der neuen Kalibrierung (MMJJ).
    -> Folgerung für den Treiber: Den Methodennamen nicht fest im Code
       hinterlegen, sondern über die config.yml oder als Parameter setzen.
[x] Dauer eines BakeOut?
    -> 20 Minuten. Den Timeout im Treiber entsprechend wählen.
[x] Rohdaten eines echten Laufs?
    -> Sind hochgeladen als Beispieldaten: "testdata_microgc.fusion-data"
[ ] Das Peak-Tabellen-Schema der Beispieldaten mit der Annahme im Code
    vergleichen.
